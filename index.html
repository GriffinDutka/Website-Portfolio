How I know they work

  • Measured

    Each agent is scored on catch rate and held under a noise ceiling, so it finds real incidents without burying analysts in alerts.

  • Evaluated

    Every agent has evals. A prompt or model change is tested against known cases before analysts rely on it.

  • Reviewed

    Analysts review agent output and their corrections feed back into tuning. Fewer than 2.5% of AI-drafted reports need a correction.

  • Least privilege

    Agents reach logs and data through scoped API connectors, MCP servers, OAuth, and managed secrets. Nothing gets broader access than its job needs.

Selected work

Dead Man Switch

A three-layer offboarding lockdown, built after a P0 incident involving post-termination device access. It has covered 1,500+ terminations with no unauthorized access afterward, including on devices that never come back online.

  • Layer 1, firmware-level OS freeze. An embedded offline timer locks any device that stays offline for 30 days. Users get warning emails 7 days and 24 hours before, so nobody is caught off guard.
  • Layer 2, cached credential clearing. RMM and MDM heartbeat scripts clear cached credentials after 3–5 days of inactivity, depending on job title. Normal login comes back once the device syncs with the directory.
  • Layer 3, monitoring. 20+ blocking controls and monitors across DLP, UAM, and SIEM watch for any post-termination activity.

Email review at scale

Archive exports decode each message body and attachment into readable files. An orchestrator agent sorts the mail and hands each message to a specialist agent. Coverage went from 500 to 6,000+ emails a day, and the daily triage that used to take about 5 hours now runs in 15 minutes.

Stale data cleanup

Custom Mac and Windows discovery scripts surfaced 80,000+ GB of stale local data across 4,500+ devices. A deletion pipeline with tiered rules per department now clears it automatically.

High-risk user reviews

Users on PIPs, suspected of IP theft, or showing anomalous behavior used to need weeks of manual review. iPaaS workflows and AI review of SIEM alerts, data movement, and targeted email now produce a structured report.

Incident response program
